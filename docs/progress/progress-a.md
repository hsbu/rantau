## Agreed foundation decisions and integration boundaries

- The requester approved the S-01/S-02/A-01 proposal on 2026-10-16 and confirmed the product name Rantau. This file consolidates the former foundation notes and implementation proposal; executable field definitions remain in `backend/contracts/`, with product requirements in the MVP/roadmap.
- Money uses strict nonnegative JavaScript-safe integers: IDR scale 0 (whole rupiah), CNY scale 2 (fen). Payment amounts are positive. Quote rates are exact decimal strings in destination major units per source major unit, rounded half up to destination minor units; totals equal principal plus fee. Times are timezone-aware. `terms_hash` is an opaque trusted-service digest, never generated authority from the agent.
- Fixture aliases remain `stu_001`, `par_001`, `acct_idr_01`, `uni_cn_01`, `obl_2026_demo_01`, `benef_uni_cn_01`, `quote_001`. The fictional November clock, two quotes and errors live in `tests/fixtures/`. Both quotes deliver CNY 20,000 for IDR 46,025,000 / 46,050,000 and expire after 15 simulated minutes. Fake execution cannot approve or debit.
- Actor identity comes from a verified server session, never a message/header claim. `verified_actor` and `agent_services` stay closed until real B/C adapters are connected; no mock gate is loaded in the integrated application. `RunRepository` is an integration seam, not durable production storage. The DB probe does not create migrations or financial tables.
- Payment delivery and verified university posting are distinct. `UniversityPort.reconcile` submits/rechecks evidence; it cannot approve cases or post credit. The A-01 graph receives only read/triage capabilities and no executor, approval writer, hold-clearing or ledger-posting tool. Tests assert forged authority cannot change actor context and provider uncertainty cannot cause a retry.
- OpenAI receives bounded user text with common sensitive identifiers redacted, not server actor/session data, balances or tool output. Classification returns only an allowed intent or clarification; graph paths, tools and deterministic replies remain fixed. The adapter uses `OPENAI_MODEL`, bounded retries/output and `store=False`, with safe refusal/invalid/incomplete/timeout/error handling. Live model access, accuracy and latency have not been measured.
- Current agent runs are single-turn; `conversation_id` is reserved for later storage. Tracking recognizes synthetic `transfer_...` references. Verified payment-to-obligation linkage, full tuition dialogue, approval resumption, recovery execution and the chat UI remain later work; do not infer those features from the foundation demo.
- Generated OpenAPI/TS, environments, caches and temporary PR bodies stay ignored. Lockfiles are committed. ESLint 10/TypeScript ESLint replaces the Next-specific preset after its transitive glob dependency audit finding; Next compilation/types still run separately.
